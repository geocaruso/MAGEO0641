9  Reading and writing data to and from R

9.1 Reading delimited files

Text files and delimited files can easily be imported in R using the function read.table(). You can play with the values of the different arguments to adapt to the format of your file. You have the possibility to load a file

  • stored locally: writing the path to reach it
  • chosen interactively and stored locally
  • from the web using its url.
?read.table

heartSA <- read.table("data/SAheart/SAheart.txt", header=T, sep=',', row.names=1)
heartSA <- read.table(file.choose(), header=T, sep=',', row.names=1)
heartSA <- read.table("https://web.stanford.edu/~hastie/ElemStatLearn/datasets/SAheart.data", 
                      sep=",", head=T, row.names=1)

There exist also some preset functions to read tables with some specific formats. Here again you can play we the values of the different arguments to load your database in an accurate way.

read.csv(file, header = TRUE, sep = ",", quote = "\"",
         dec = ".", fill = TRUE, comment.char = "", ...)

read.csv2(file, header = TRUE, sep = ";", quote = "\"",
          dec = ",", fill = TRUE, comment.char = "", ...)

read.delim(file, header = TRUE, sep = "\t", quote = "\"",
           dec = ".", fill = TRUE, comment.char = "", ...)

read.delim2(file, header = TRUE, sep = "\t", quote = "\"",
            dec = ",", fill = TRUE, comment.char = "", ...)

9.2 Files from specific software

Some databases are exported from other software and have atypical formats.

  • You first need to install (once per machine) and load the R package foreign.
# install.packages('foreign')
library(foreign)
  • Then you can load the following different formats
# Read the SPSS data
read.spss("example.sav")

# Read Stata data into R
read.dta("c:/mydata.dta") 

library(xlsx)

# first row contains variable names
read.xlsx("c:/myexcel.xlsx", 1)

# read in the worksheet named mysheet
read.xlsx("c:/myexcel.xlsx", sheetName = "mysheet") 

# The package `readxl` can also be helpful.

library(sas7bdat)

# Read in the SAS data
mySASData <- read.sas7bdat("example.sas7bdat")

A recurrent use case for geographers is to read the table component of a ‘shapefile’ i.e. a dbf file. You use the read.dbf functrion from the foreign package to do so.

9.3 Writing a dataframe to a file

You can also export a dataset

write.table(heartSA, file = "data/SAheart/NewSAheart.txt")
write.csv(heartSA, file = "data/SAheart/NewSAheart.csv")
write.csv2(heartSA, file = "data/SAheart/NewSAheart.csv")

However, in case it is for further use within R, we recommend you use the RDS format, which works with any type of R object and is often very effective in terms of file size.

saveRDS(heartSA,"data/SAheart/NewSAheart.rds")
NewSAheart<-readRDS("data/SAheart/NewSAheart.rds")

9.4 Long and wide datasets

Coming from the spreadsheet world you are most probably used to see each variable of interest to be presented as a separate column.

9.4.1 A typical case

A typical case is a that of a variable X, varying across spatial units or across individuals, for which the evolution is followed through time. For example you have n countries, each being a row, and several years at which the X variable was recorded, each year being a column with title indicating X and the year (e.g. X.2006, X.2016, X.2026). They are typically appended on the right side of a variable titled Country.Name In that case, the data is said to be in wide format. Its long version would be a case where you have a n (coutries) x 3 (years) rows and the columns are Country.Name, X and time.

The wide data:

wide <- data.frame(
  Country.Name = c("Australia", "Brazil", "South Africa", "Argentina", "New Zealand"),
  X.2006 = c(20.7, 186.1, 47.9, 39.3, 4.2),
  X.2016 = c(24.2, 205.2, 56.2, 43.6, 4.7),
  X.2026 = c(27.0, 217.0, 63.0, 47.0, 5.3)
)
wide
#>   Country.Name X.2006 X.2016 X.2026
#> 1    Australia   20.7   24.2   27.0
#> 2       Brazil  186.1  205.2  217.0
#> 3 South Africa   47.9   56.2   63.0
#> 4    Argentina   39.3   43.6   47.0
#> 5  New Zealand    4.2    4.7    5.3

And its long version built after repeating the countries and years and combining X vectors one below each other.


long<- data.frame(
  Country.Name = rep(wide$Country.Name, each = 3),
  Year = rep(c(2006, 2016, 2026), times = nrow(wide)),
  X = c(rbind(wide$X.2006, wide$X.2016, wide$X.2026))
  )
long
#>    Country.Name Year     X

#> 2     Australia 2016  24.2

#> 6        Brazil 2026 217.0
#> 7  South Africa 2006  47.9
#> 8  South Africa 2016  56.2
#> 9  South Africa 2026  63.0

Building this dataset can become tedius or risky since you want to keep the right order of countries and years and X values.

Fortunately there is a reshaping function that makes the transformation from wide to long or log to wide easier.

See:

long <- reshape(wide, direction = "long", varying = c("X.2006", "X.2016", "X.2026"), idvar = "Country.Name")

rownames(long) <- NULL

9.4.2 A more complex case to compare reshape and pivot

The reshape function was built to handle time varying data, hence the naming of the arguments. It can be applied to variations non related to time and for more complex with some easy tricks. To some, its tidy counterparts may seem more practical when handling more complex cases where the widening, especially when the lengthening takes several variables (at the expense of having to call a package, using two separate functions and a different way of handling variable names).

Suppose 4 students rated 2 holiday types across 2 years. Let’s generate the data consisting of 16 rows, i.e. 4 students x 2 types x 2 years

long <- data.frame(
  Name = rep(c("Jorge", "Celine", "Mariam", "Elvira"), each = 4),
  Holiday = rep(rep(c("Mountain", "Beach"), times = 2), times = 4),
  Year = rep(rep(c(2026, 2027), each = 2), times = 4),
  Recommendation = c(3, NA, 3.5, NA,
                     4, 3.5, 4.5, 4,
                     5, 4, 4.5, 4.5,
                     4.5, 5, 4, 5)
)

long_b <- reshape(wide_b)
row.names(long_b) <- NULL
